# Ideal Technology Solutions — Project Brief

## Company facts
- Name: Ideal Technology Solutions, LLC (ITS)
- In business since 2001 (25 years)
- Headquarters: Southfield, Michigan. Serves Detroit and Metro Detroit. One project in Atlanta.
- Builds software on: .NET, Azure, Azure SQL, Power BI, React, Angular
- Website platform: WordPress with a fully custom theme
- Standard call to action: "Book a 30-minute appointment with a client advisor."

## Five service pillars (the website lists only these)

### 1. Managed IT & Infrastructure
Offered today: managed IT services, network design, IT support, hardware and software sales, Microsoft 365, procurement, licensing, device setup.
Expanding into: infrastructure modernization, structured managed services, technology lifecycle management, connected technology.

### 2. Cloud & Cybersecurity
Offered today: cloud infrastructure, Microsoft cloud deployments, security software, endpoint protection, licensing, backup, secure application deployment.
Expanding into: Azure migration, identity and access management, advanced cybersecurity, compliance, cloud operations, DevOps, disaster recovery.

### 3. Custom Software & Digital Products
Offered today: website design and development, custom web applications.
Expanding into: custom software, mobile apps, business portals, APIs, system integration, UX/UI design, MVP development, product modernization.

### 4. Data, AI & Automation
New capability. Expanding into: Power BI, dashboards, business intelligence, data integration, AI applications, AI chatbots, workflow and process automation.

### 5. Digital Transformation & Technology Consulting
Offered today: technology consulting, decision support.
Expanding into: transformation strategy, IT and process audits, technology roadmaps, process improvement, system modernization, IoT.

## Case studies (approved for use)
1. **Sean Anderson Foundation** (Nonprofits) — custom CMS website with embedded donations. Results published by the foundation: 10,000+ youth and families served, $3M+ raised, 15,000 school supplies and 16,500 backpacks distributed.
2. **Chemico Credit Hold Repository** (Manufacturing) — internal business application built with Angular, .NET Core, SQL Server and Azure, secured with Microsoft Entra ID. Tracks credit holds through a five-stage resolution scale with full edit-history logging. Proof for Pillars 2, 3 and 4.
3. **DPSCD Foundation** (Education, K-12, Nonprofits) — PHP CMS website with a fundraising platform and YouTube, Instagram and Google Maps integration.
4. **Guidepoint Systems** (Automotive) — WordPress website with four audience paths (OEMs, dealers, fleets, vehicle owners) and a secure customer portal.
5. **Usher's New Look** (Nonprofits) — HTML5/CSS3/JavaScript website with a city-based application flow.
6. **Rozafa Transport** (Transportation & Logistics) — general portfolio only; do not use on industry pages.
